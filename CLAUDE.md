In term of tools and components:
 - Reuse the existing UI components before trying to create new ones.
 - Reuse the existing css styles before trying to create new ones.
 - When you are using external libraries / database access like Supabase, always use or create an intermediate service layer, because some external libraries could be replaced at some point.

Always favor refactoring of similar existing code / components / UI / algorithm before starting to write new code. It of course only applies if something is already existing.

In plan and agent modes, do not hesitate to ask questions if you need more information, in particular for huge complex tasks.

For the architecture / high complexity code related tasks, behave like a Senior Software engineer / an architect.

For the UI and design tasks, behave like a Senior UI designer.
For the UI, please always implement a solution for BOTH mobile and desktop.

Challenge the solutions I am proposing (if there is an existing better way, don't challenge everything for the sake of challenge...).
